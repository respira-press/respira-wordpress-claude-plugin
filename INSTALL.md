# Installing Respira for Claude

This guide installs the Respira plugin for Claude. The plugin brings Respira's skills, slash commands and a reviewer agent, all plain text. It starts no program on your computer, needs no Node.js, connects to nothing and sends nothing.

## Install the plugin

### Claude Code (terminal or VS Code)

Open `/plugin`, find **Respira for WordPress** in the directory and install it. It asks for no setting.

### Cowork, claude.ai and the Claude apps

Install the plugin from **Customize, Plugins, Discover** (the directory).

## What it needs

A WordPress site with the Respira for WordPress plugin, and the Respira tools present in the conversation. Without them the skills stop and say so. Respira for WordPress: https://www.respira.press

## Uninstalling

In Claude Code run `/plugin` and remove Respira. In Cowork and the apps, remove the plugin from **Customize, Plugins**. Nothing about your WordPress content changes when you uninstall the plugin.
